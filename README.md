# 💎 Diamond Mines

A fun and interactive Stake.com-inspired **Diamond Mines** game built using **Flask** for the backend and **HTML/Tailwind CSS/JavaScript** for the frontend. An AI model is also integrated to suggest the safest tile to click using a trained neural network.

---

## 🚀 Features

- 🎮 5x5 interactive grid with mines
- 💰 Place bets and cash out with increasing multipliers
- 🤖 AI-powered safe tile suggestions
- 💡 Visual feedback, animations, and styling with TailwindCSS
- 🔥 Mine animations with big green 💎 icon on loss

---

## 🧰 Tech Stack

- **Backend:** Flask (Python)
- **Frontend:** HTML, TailwindCSS, Vanilla JS
- **AI Model:** LSTM Neural Network (Keras/TensorFlow)
- **API Communication:** JSON over HTTP (Fetch API)
